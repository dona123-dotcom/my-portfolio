Why was CSS created?

In the past, developers used HTML tags such as <font> and color attributes to format pages. On large websites, repeating formatting on every page was difficult, time-consuming, and expensive. The World Wide Web Consortium (W3C) created CSS to make formatting easier and separate design from content.

03 / Why CSS matters

Benefits of CSS

One stylesheet can make website design easier, faster, and more consistent.

⏱️

1. Time-saving

Write formatting code in a separate CSS file and reuse it across many HTML pages.

⚡

2. Loading speed

The browser can store a CSS file and reuse its cached copy when visiting linked pages.

🛠️

3. Easy modification

Change the shared CSS file once, and the linked pages can reflect the new formatting.

🎨

4. Better appearance

CSS makes webpages more attractive, consistent, and visually organized.

📖

5. Better readability

Appropriate fonts, sizes, and colors make content easier to read.

🧩

6. Separation of design and content

Update the design in the CSS file without changing the HTML structure.

📱

7. Responsive pages

CSS helps pages adapt to different screen sizes, such as computers, tablets, and phones.

04 / Build the code

The Basic Structure of CSS

CSS uses a simple rule: choose an HTML element, choose what to change, and give it a value.

Selector { Property: Value; }
Selector

What element?

Represents the HTML element or group of elements to format, such as body or h1.

Property

What to change?

Specifies the feature you want to change, such as color, font-size, or spacing.

Value

How to change it?

Specifies the setting for the property, such as brown, 24px, or center.

Example CSS rule
h1 { color: brown; font-size: 24px; }
05 / Three methods

How to Add CSS to HTML

There are three ways to insert CSS into an HTML webpage.

TypeWhere is the CSS written?Typical use
Inline CSSDirectly inside an HTML element using the style attribute.Styling a specific element.
Internal CSSInside a <style> element in the HTML head.Styling one individual webpage.
External CSSIn a separate .css file linked to HTML.Consistent formatting across multiple pages; preferred for large websites.
06 / Main lesson focus

External CSS

External CSS keeps the design in a separate file, so multiple webpages can share the same styles.

📄

Separate file

CSS code is saved in a separate file with the .css extension.

🔗

Link to HTML

Use the <link> tag inside the <head> section.

♻️

Reuse styles

One external CSS file can format many webpages across a website.

🚫

No HTML tags

An external CSS file contains CSS rules, not HTML tags.

The link tag
<link href="fileName.css" rel="stylesheet">
href

Specifies the CSS filename and file path.

rel="stylesheet"

Tells the browser that the linked file is a stylesheet that should be applied to the page.

Where?

Place the link element inside the HTML document's <head> section.

Let's see the code in action

The HTML file links to mystyle.css. The CSS file controls the page background and heading style.

First: HTML File Code
<html> <head> <link rel="stylesheet" href="mystyle.css"> </head> <body> <h1>Here is the page title</h1> <p>Here the content appears</p> </body> </html>
Second: CSS File Code
body { background-color: lightblue; } h1 { color: brown; font-size: 24px; }
